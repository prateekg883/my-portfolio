# Prateek Gupta — Personal Portfolio

A dark-themed, glassmorphism personal portfolio website built with **HTML5, CSS3, and Vanilla JavaScript** — no frameworks.

🔗 **Live site:** https://prateekg883.github.io/my-portfolio/

---

## ✨ Features

- **Dark glassmorphism UI** — glowing gradient accents, frosted glass cards, smooth hover effects
- **Fully responsive** — works on desktop, tablet, and mobile
- **Animated hero section** — typing effect, gradient name text, floating profile photo
- **Live GitHub stats** — real-time stats, top languages, and streak widgets pulled directly from GitHub
- **Certifications section** — 9 certificates with direct "View Certificate" links
- **Projects showcase** — 5 real projects linked to their GitHub repos
- **Working contact form & social links** — GitHub, LinkedIn, LeetCode, Email

## 📁 Pages

| Page | Description |
|------|-------------|
| `index.html` | Home — Hero, About preview, Skills, Projects, Achievements, Certifications, GitHub stats, Contact preview |
| `about.html` | Full bio, education, and background |
| `projects.html` | Detailed project breakdowns with features and tech stack |
| `contact.html` | Contact form and direct contact links |

## 🛠️ Built With

HTML5 · CSS3 (Flexbox, Grid, CSS Variables, Keyframe Animations) · Vanilla JavaScript (ES6+)

## 🚀 Running Locally

Just open `index.html` in any modern browser — no build step or server required.

For live-reload while editing, use the VS Code **Live Server** extension.

## 📦 Deployment

This site is deployed via **GitHub Pages**, serving directly from the `main` branch.

To deploy your own copy:
1. Push this repo to your GitHub account
2. Go to **Settings → Pages**
3. Set source to the `main` branch, root folder
4. Your site goes live at `https://<username>.github.io/<repo-name>/`
